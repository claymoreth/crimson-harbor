An original open-world crime game in Port Valen — an entry for [make.fun gta6-01](https://make.fun/bounty/gta6-01).

Leo Marlow, a getaway driver fresh out after four years inside, is back in Port Valen to find who set him up and pay a debt to fixer Mara Voss. Drive, fight the Harbor Kings, lose the Port Valen police, and work seven story jobs across nine districts.

## Play

Open `game/index.html` in a desktop browser, or serve the `game/` folder:

```sh
node serve.ts
```

Then open http://localhost:8080. No network requests — the game is fully offline.

## Controls

- **WASD** — walk / drive
- **Mouse** — aim, click to shoot
- **Shift** — sprint
- **Space** — handbrake drift
- **F** — enter / steal a vehicle
- **E** — interact / pick up
- **Q** — previous radio station
- **R** — reload
- **M** — city map / pause

## Features

- Main menu with six selectable drivers and a save slot (CONTINUE)
- Car chases with a live police response panel (unit name, distance, RAMMING / PURSUIT / ROADBLOCK), wanted stars 1–5, and heat lost by breaking line of sight
- On-foot shootouts with enemy markers, a boss dialog before the fight, and missions that chain into a police escape
- Full city map (M) with nine districts, seven story jobs, a GPS route, and a complete legend
- Seven missions — the first three fully playable to completion — plus collectibles, properties, respray, radio, and a localStorage save
